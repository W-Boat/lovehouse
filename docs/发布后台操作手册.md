# 生日小屋发布后台操作手册

通过发布服务器的 HTTPS 地址访问 `https://server.080726.xyz/lovehouse/admin/`。从管理员处取得发布令牌，在后台输入。令牌只用于本次页面会话。

1. 在内容页面点「读取已发布」，以当前线上版本为草稿起点。
2. 在「素材库」上传图片、音频或 LRC 歌词，然后复制素材链接。已上传素材可预览图片、查看大小和删除。已发布配置引用的素材需要先从配置中移除并发布，随后才能删除。
3. 把链接填入场景背景、礼物图片、回忆照片或唱片房。场景、互动和传送门可用表单编辑；批量修改可导入 JSON。
4. 点「校验草稿」，确认后再点「发布」。如遇版本冲突，先导出草稿，再读取最新版本并合并修改。

素材库单文件上限 16 MiB，云端场景背景另有 4 MiB 客户端上限。独立 HTML 小游戏需发布到允许 iframe 的独立站点，然后把 HTTPS 地址填进小游戏配置。发布配置和素材链接供游戏客户端公开读取。
