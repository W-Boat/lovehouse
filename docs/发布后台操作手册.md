# 生日小屋发布后台操作手册

后台地址为 https://server.080726.xyz/lovehouse/admin/ 。输入管理员提供的发布令牌。令牌保留在当前页面内，刷新后需要重新输入。

## 编辑与发布

1. 首次编辑可点「载入线上配置」，以已发布内容作为起点。后台会先保存当前草稿，再载入线上内容。
2. 若已导入文件或恢复本机草稿，点「连接服务器」取得当前修订号。此操作保留正在编辑的草稿。
3. 文案、场景、互动、礼物小游戏绑定和传送门支持表单或 JSON 编辑。完整 JSON 可从「完整配置」批量修改，也可导入或导出文件。唱片房、替换素材等以页面实际提供的编辑入口为准。
4. 点「校验草稿」，再点「发布」。确认窗口会列出有变化的分区。确认后，玩家下次启动同步此配置。

遇到版本冲突时，先导出草稿，再连接服务器并对照最新内容合并。发布会检查当前修订号，冲突时不会覆盖线上版本。

## 本机草稿

有效的编辑内容约在停止输入 800 毫秒后保存到当前浏览器。页面显示「本机草稿已保存」时表示保存成功。重新打开后台后，可点「恢复草稿」，再点「连接服务器」。草稿按后台地址区分，浏览器清理网站数据会移除草稿。JSON 暂时无效时，应先修正格式并确认保存提示；重要内容另行导出。

## 素材库

点「刷新列表」读取素材。支持按文件名或素材 ID 搜索、按类型筛选和分页。可多选图片、音频或 LRC 文件上传，逐个查看进度及本次上传结果。图片可放大预览，音频可试听，歌词可读取文本；复制链接后填入场景背景、礼物图片、回忆照片或唱片房配置。

支持 PNG、JPEG、WebP、AVIF、MP3、WAV、OGG、M4A 和 LRC。单文件上限 16 MiB，LRC 上限 512 KiB，云端场景背景另有 4 MiB 客户端上限。相同文件按内容哈希复用。当前发布版本或保留历史版本引用的素材会阻止删除，以便回滚后继续显示。

独立 HTML 小游戏发布到允许 iframe 嵌入的站点，再把 HTTPS 地址填入小游戏配置。发布配置和素材链接供游戏客户端公开读取。

## 发布历史与回滚

在「发布历史」点「读取发布历史」，可查看修订号、保存时间和当前版本标记。「导入草稿」把选中版本载入编辑器，适合修改旧版内容后重新发布；此操作本身不会切换线上版本。

需要直接恢复旧版时，先连接服务器取得当前修订号，再对目标版本点「回滚」并确认。玩家下次同步会使用恢复后的配置。回滚会保留原先线上版本，后续仍可从历史恢复。列表时间是该修订首次保存的时间，重复发布相同内容不会生成新的内容修订号。

素材库新增「引用」，列出当前及历史发布配置中的 JSON 位置和修订号。可据此定位引用来源；历史版本仍使用的素材受删除保护。
