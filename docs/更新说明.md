# 生日小屋互动扩展版

启动：安装 Node.js 后在源码目录运行 npm install、npm run dev。部署 dist 中的全部文件，支持子目录。静态文件需要 HTTP 服务，不能直接双击 index.html。

## 本次更新
- 由四个区域扩为六个：玻璃花房使用全新 imagegen 背景；回忆放映室复用庆祝后的小屋背景。
- imagegen 生成四格透明坐姿图集（男女正反面），保留原角色服装。所有座位切换坐姿，起身恢复位置。蛋糕桌两侧椅子可坐。
- 扩大点击范围、降低同伴抢占点击优先级；走到目标后自动互动，走近期间暂停同伴追随，点击其他地面取消待执行动作。
- 六种小游戏：花瓣配对、萤火节拍、接花雨、顺序记忆、星星收集、剪丝带。场景游戏点首次靠近自动触发，也能从工具栏重玩。首次拆礼物前出现挑战，可直接跳过。
- 陪伴菜单支持跟随、牵手、拥抱、鬼畜舞；唱片机藏有舞蹈彩蛋。牵手以连线表现，拥抱为靠近与轻晃动画。
- 可隐藏地图，显示当前位置，点击列表或地图标记走近。点阵字体 DotGothic16（SIL OFL，许可随包附带；部分中文使用系统字体回退）。
- 晴朗／雨／雪，月夜／晨昏／日间暖光独立设置并本地保存。时段是环境色调变化，原背景月亮不移除。天气图标随选择变化。
- 花房心愿种子与放映室未来留言，最多 500 字，本地保存。

## 验证
TypeScript 与 Vite 构建通过；29 项测试通过。浏览器验证自动入场、地图选座、两人坐姿、起身、小游戏退出、天气设置和走近后拥抱，无 pageerror。移动端路径与旋转坐标由现有自动测试覆盖，未在实体手机上验收。

## 素材
新增 public/assets/greenhouse.png、sitting.png 通过内置 imagegen 生成；提示词见 imagegen-expansion-prompts.json。没有购买任何付费小游戏，六种小游戏均内置实现。


## 十场景版本新增（本轮连续两次各增加两个）

四张全新背景均由内置 imagegen 生成并已放入 public/assets，精确提示词保存在 imagegen-four-scenes-prompts.json。

- 云上终点站：从萤火森林的「去云上终点站」进入。候车长椅双人坐姿、纸飞机飞行动画、三声站钟、看云与车票小游戏。
- 晚安邮局：从月光海岸的「去晚安邮局」进入。檐下双人坐姿、独立明信片编辑与本地保存、生日邮戳和听雨。
- 潮汐水族馆：从星光栈桥的「去潮汐水族馆」进入。窗前双人长椅、水母浮游动画、海底回声与独立悄悄话保存。室内不显示雨雪粒子。
- 星野露营地：从云上终点站的「去星野露营地」进入。篝火长椅、分享棉花糖、可点亮营灯、晚安故事与节拍小游戏。

每处均可沿原路返回。场景小游戏自动触发记录改为按区域独立计算。留言仍仅保存在当前浏览器，不会实际寄送，也没有线上服务器。

静态日出、雨巷等属于背景美术；手动天气和时段仍是叠加的氛围效果，不会重绘背景。

十场景最终验证：构建通过，31 项自动测试通过。浏览器验证四个新场景往返、四种新座位、纸飞机、棉花糖分享、点灯、明信片与水族馆留言保存；无 pageerror。
