# 生日小屋 2.0 · 中央构图与互动修订

本版共有 18 个区域，使用 Phaser、TypeScript 与 Vite。网页和 Windows 客户端共用资源。浏览器验收和客户端构建在 GitHub Actions 执行，不在本地部署。

## 场景

新增暖汤足浴屋（露营地入口）、云端生日集市（摩天轮入口）、极光玻璃屋（终点站入口）。三张 imagegen 背景以画面中央的双人座、足浴池、茶几或甜点摊为主体，外围布置细节和可走路径。

回忆室、魔法世界、鬼屋、电影院、摩天轮及火星增加独立家具层。中央软座、茶几、书柜、点心车、棋盘和灯具有对应热点与碰撞。座位使用坐垫锚点；角色先走近，再坐下、保持、起身。人物自然高度调整为 64 个世界单位，以改善家具与角色比例。

## 动作和天气

牵手使用独立并排控制器；只有掌部接触时显示双人图。受阻时松手，依照足迹跟随，走宽处重新靠近。没有连接线。拥抱、递花、分享等使用双人接触图帧；取消清理待执行动作。

房间窗户按照玻璃窗格反馈昼夜、雨雪，木框和室内地板不参与降水。足浴屋有蒸汽与水波，集市有灯光和花瓣，极光屋有壁炉暖光及热饮蒸汽。

## 界面

入口为像素小屋插画和 20 格进度条。加载、字体与角色准备完成才进入装扮页面。出口名称使用固定屏幕字号的像素木牌，不再随相机缩放放大成黑色文字块。

顶部统一工具栏、世界地图、背包、设置与装扮。礼物各自绑定小游戏，领取后可从礼物详情重玩；没有独立小游戏工具按钮。

## 验证边界

已通过 39 项离线自动检查。最新浏览器截图与检查结果以 docs/验收报告.md 对应的 GitHub Actions 提交为准。未执行 Android/iOS 实机验收。美术适配、座椅遮挡与动作接触仍需结合截图逐项复核，不能仅凭测试通过认定效果完善。
