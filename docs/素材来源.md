# 素材来源与许可

## 视觉

原始十场景与角色来自用户提供的 birthday-cottage-source (3).zip；新增／改绘素材通过内置 imagegen 生成。原图在 tools/art-source，发布包使用压缩 WebP；新提示词清单见 imagegen-v2.json 与 imagegen-central-compositions.json。
角色图集使用游戏内切帧与分层搭配。GIF 为图集帧合成的预览，不宣称本次工具直接输出了 GIF。

## 音乐

“Moonlight” 与 “Childhood” — Scott Buckley，CC BY 4.0。
https://www.scottbuckley.com.au/library/moonlight/
https://www.scottbuckley.com.au/library/childhood/
https://creativecommons.org/licenses/by/4.0/

作者网站下载端点在本环境返回 406；本次使用其已按同一许可分发的 M4A 副本，来源 https://github.com/JilinJL/PixelWalk/tree/main/assets/audio ，副本注明原始文件来自作者网站。录音未重新作曲或变速；副本为 AAC 160 kb/s，运行时调整音量、循环与淡入淡出。游戏设置内提供署名。

## 音效

Kenney UI Audio，CC0，原来源 https://kenney.nl/assets/ui-audio 。WAV 副本来源 https://github.com/Calinou/kenney-ui-audio 。仅选用五个点击音效。

## 字体

Fusion Pixel 12px Proportional zh_hans，来自 https://github.com/TakWolf/fusion-pixel-font ，字体 OFL 1.1。字体来源文件与上游许可保存在 tools/font-source；public/assets 中包含 FusionPixel-LICENSE-OFL.txt、构建程序 MIT 许可及 Cubic11、Galmuri 上游许可，发布包一并保留。构建生成固定文案子集与按 Unicode 范围加载的补充字体。

## 软件

Phaser、Vite、TypeScript、Playwright、Tauri、Pillow、FontTools 使用各自开源许可。游戏不捆绑完整浏览器；Windows 使用系统 WebView2。

## 北京与遂平

什刹海、鼓楼胡同、嵖岈山、天磨湖和糖葫芦车间各使用一张独立生成的像素背景。场景布局按游戏动线重新设计。北京地标参考北京市政府《漫步北京》文化探访线，遂平奇石与湖泊参考中国天气网河南站《遂平嵖岈山》。生成提示词与资料链接见 regional-art-imagegen.json。


### 校园、主屋猫猫与唱片房

- `highschool.webp`：ImageGen 原创，遂平一高题材的化名像素校园，不是现实校舍复刻。参考与生成记录见 `tools/art-source/highschool.json`。
- `musicroom.webp`：ImageGen 原创；再次编辑去掉静态唱针，由游戏动态绘制唱针。母图保存在 `tools/art-reference/musicroom-with-arm.png`。
- 主屋团团复用现有 `pet-cat.webp` 原创猫猫动画，增加地面寻路和交互。
- HeoMusic： https://github.com/zhheo/HeoMusic ，固定提交和文件摘要见 `public/heomusic/UPSTREAM.json`。Apache-2.0 许可文件与 APlayer、MetingJS 的 MIT 许可均随资源提供；场景适配修改已在源文件注明。
- 唱片房默认离线音乐继续使用原有 Scott Buckley 的 Moonlight、Childhood，署名与 CC BY 4.0 来源沿用现有音频清单；未下载或打包商业歌单音频。
