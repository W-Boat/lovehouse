# 素材来源与许可

## 视觉

原始十场景与角色来自用户提供的 birthday-cottage-source (3).zip；新增／改绘素材通过内置 imagegen 生成。原图在 tools/art-source，发布包使用压缩 WebP；新提示词清单见 imagegen-v2.json。
角色图集使用游戏内切帧与分层搭配。GIF 为图集帧合成的预览，不宣称本次工具直接输出了 GIF。

## 音乐

“Moonlight” 与 “Childhood” — Scott Buckley，CC BY 4.0。
https://www.scottbuckley.com.au/library/moonlight/
https://www.scottbuckley.com.au/library/childhood/
https://creativecommons.org/licenses/by/4.0/

作者网站下载端点在本环境返回 406；本次使用其已按同一许可分发的 M4A 副本，来源 https://github.com/JilinJL/PixelWalk/tree/main/assets/audio ，副本注明原始文件来自作者网站。录音未重新作曲或变速；副本为 AAC 160 kb/s，运行时调整音量、循环与淡入淡出。游戏设置内提供署名。

## 音效

Kenney UI Audio，CC0，原来源 https://kenney.nl/assets/ui-audio 。WAV 副本来源 https://github.com/Calinou/kenney-ui-audio 。仅选用五个点击音效。

## 字体

Fusion Pixel 12px Proportional zh_hans，来自 https://github.com/TakWolf/fusion-pixel-font ，字体 OFL 1.1。字体来源文件与上游许可保存在 tools/font-source；发布时保留许可。构建生成固定文案子集与按 Unicode 范围加载的补充字体。

## 软件

Phaser、Vite、TypeScript、Playwright、Tauri、Pillow、FontTools 使用各自开源许可。游戏不捆绑完整浏览器；Windows 使用系统 WebView2。
