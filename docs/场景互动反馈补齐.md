# 场景互动反馈补齐记录

2026-11-13，本轮实现待下一次CI截图验收。

此前 scene.remember 的通用 animatePlace 仅摆动已有prop，很多烘焙物件没有独立图层，实际只保存moment和回一句话。本轮新增 PlaceEffects 控制器，用各物件的坐标绘制实际操作：书页翻转、双杯倒茶与蒸气、添柴火苗、邮戳盖下、药水变色、棋子移动、箱盖打开、投影光束与转轮、花房浇水及开合天窗等。每次点击可重播，7秒后回收；切区清空，不控制人物位置，不产生过期计时器。

每区至少登记两种不同机制，均与真实物件ID对应：

|区域|独立反馈例|
|---|---|
|主屋|添柴火苗、翻页、双杯茶、花束、灯、烛焰、柜盖|
|海岸|摆动风铃、海螺回声波纹|
|森林|泉水喷流、靠近的萤火、灯串|

花房原先除通用补位外只有软椅、种子、游戏，不能算内容足够。本轮新增真实喷壶和通风天窗，补软椅明确sit文案；主代理负责种子写信成功后的remember调用，取消不能触发。花房现在去掉small-note和通用keepsake后有6个候选，仍包含小游戏/展示；不能仅数字证明6个核心物件都有具象操作。海岸swing/bench/sea的坐下由main原有分支提供，不能因为places.sit统计为0就判断没有座位。

验证：TypeScript通过；place-effects、runtime、world共21测试通过，覆盖事件真实ID、每区不同机制、结束回收、重播、切区清理和原入口可达。测试不证明动画对齐或美观。下一次CI必须检查图形是否对齐烘焙物体、是否与原environment旧反馈重叠；所有6有效互动及2事件的体验质量仍需逐区完整游玩。
