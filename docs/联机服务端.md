# 联机服务端

入口 `node server/index.mjs`，WebSocket 路径 `/online`，HTTP `/health`。本地没有启动服务；真实监听与双连接测试只在 GitHub Actions 执行。部署时使用反向代理提供 HTTPS/WSS。

环境变量：`PORT` 默认 8787，`HOST` 默认 0.0.0.0，`ALLOWED_ORIGINS` 为逗号分隔的网页 Origin；生产环境必须配置自己的来源。空值接受任何 Origin，适合隔离测试而非公开生日站点。

私密房间 ID 使用随机 72 位值，重连 token 为随机 144 位，仅 welcome 发给本人。每房最多两席，主/副权限独立，断线保留 120 秒；退出释放席位。进程内保存文档和在线状态，进程重启会丢失联机房间，不替代网页本地存档。聊天不持久保存。主玩家离开不自动把副玩家提升主身份。

位置服务器检查区域、有限坐标与边界，但尚不验证 Phaser 的家具碰撞。游戏动作按房间顺序编号与转发，客户端仍需接入实际游戏状态并验证规则；不能把事件转发称为全部小游戏联机已完成。共同文档使用 revision CAS，冲突返回当前快照，不自动覆盖对方文字。

服务含消息大小、操作频率、聊天长度、房间数量上限和心跳清理。尚无账号系统或跨实例持久化；不得用于公开大规模多人服务。Dockerfile 从仓库根构建，未部署任何服务器。
