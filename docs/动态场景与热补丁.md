# 动态场景与热补丁

动态场景通过 scenes[].layers 配置，每区最多 40 层。后台的场景编辑页提供图片上传、帧图集、循环、路径与触发点表单。图集各帧尺寸必须一致，列数、行数均为 1 至 16，总帧数最多 128，每秒 1 至 24 帧。图片每边最多 4096 像素。素材推荐 PNG 或 WebP。

每层填写 id、src、x、y、width、height、depth、autoplay。frames 填 columns、rows、fps、loop。path 填 points 和 seconds。trigger 绑定同一场景的云端互动 ID。autoplay=false 时图层保持初始姿态，点击触发后播放。非循环帧停在最后一帧。路径无 frames 时循环运行。减少动态模式保留静态反馈。

~~~json
{
  "id": "floating-book",
  "src": "https://example.com/book-sheet.webp",
  "x": 320, "y": 200, "width": 64, "height": 64,
  "depth": 4, "autoplay": false, "trigger": "cloud-book",
  "frames": {"columns": 4, "rows": 2, "fps": 8, "loop": false},
  "path": {"points": [[320, 200], [320, 170]], "seconds": 2}
}
~~~

客户端每分钟检查新配置。单人、无弹窗、无小游戏、未坐下且未切场景时应用补丁。两人联机期间延后到单人状态，确保双方世界一致。正在进行的动作不会被更新截断。先准备当前场景素材，再重建世界和互动；保留角色附近合法位置。资源失败则恢复上一个配置。新资源仍可后台预缓存，配置和已成功缓存的素材可离线复用。

代码变更使用签名资源补丁，Android 和 Windows 下次启动启用；原生 API 变更需要新安装包。Windows 更新在 portable 数据目录内保存，签名和每个资源哈希都校验，启动未就绪会在下一次启动回退。设备实机验收记录见 HANDOFF。
