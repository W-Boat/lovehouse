## 当前证据与结论

基线提交 a71c1bcae20f7a85bce34694bcfd55515f64fc50。Actions 43376199495 中 Windows 构建成功，网页构建和离线测试成功，三浏览器共78项通过、3项失败。Android Actions 43376199503 成功。当前工作树另含上一轮开始的零食份数、分享完成回调与切区立绘修正，离线103项通过、1项联机服务测试由CI运行；这部分未获浏览器验收。

三个浏览器失败均在WebKit。日历自动模式未在20秒内从2028.02.28的23:59跨日；十二礼物批量流程超时；节奏游戏未在操作循环结束后完成。日志只能证明失败结果，原因仍须结合trace、页面可见性、输入焦点、帧时间和长按判定排查，不能直接归类为测试误报。新增问答在这一轮未报告失败。

原41项逐项代码证据和边界见《当前需求审计.md》。原计划要求的画面、动作、游戏全流程和真机表现仍未全部通过。源码、网页、Windows及Android最终交付包尚未统一到最新成功提交，旧ZIP不能充当当前版本。

## 发布与复核批次

第一批处理14、12、4、6、8、15以及三个WebKit失败，恢复基础游玩与导出。第二批处理5、7、9、10、11与3。第三批处理2和1。最后处理13和16，具体新增场景与开源依赖在美术/许可证调研后确定。

本地仅进行源码编辑、离线测试与静态编译。网页浏览器、Windows和Android构建继续由GitHub Actions运行。扩充Actions的Android模拟器冒烟，检查安装、冷启动、旋转、导入导出与升级；模拟器结果与实际手机结果分别记录。真机缺少的步骤保持未验证状态。

每批记录提交SHA、Actions链接、通过/失败用例、截图设备/分辨率/DPR、下载包与SHA256。最终交付同版本网页、源码、Windows、Android以及文案和替换文档。用户私人照片、信件和歌曲等继续列为待替换内容。

## 第一批实现进展

安卓导出已补PNG图片、JSON存档和旧WebView兼容桥接，使用系统文件选择器并向页面返回成功、取消、失败或繁忙状态。安卓菜单隐藏全屏按钮。音量等range控件使用方形像素滑块和双浏览器轨道样式。这些实现待Actions编译与实机复核，黑白贴图和移动端小游戏仍未解决。

路牌已增加操作设置开关，默认关闭并持久化。紧凑HUD按游戏实际宽高折叠，菜单限制在右侧，小地图与位置牌分区。小游戏Canvas移除object-fit留白，按实际比例占位；接栗子和抓娃娃支持首次触摸定位、拖动捕获，节奏按钮补指针捕获及释放。上述移动端改动已通过TypeScript和104项离线测试，浏览器触屏复核待执行。含原生导出修复的提交d58425a已通过Android Actions 43395978152。

显示缩放已接入80%、90%、100%、110%、125%五档，调整逻辑视口并缩放容器，同步触点映射。预览15秒未确认或关闭面板时恢复，确认后存档，支持重置100%。低倍率时保持主要控件的物理触摸高度，已补横屏浏览器回归用例，待Actions运行。

桃源乡进入/退出已接原生方向请求，进入竖屏、返回横屏。嵌入地址传入当前玩家称呼和性别，新档预填并在联机客端同步后恢复客端自己的身份。构建时移除主菜单赞助面板和重复隐私确认，关于页保留上游许可链接。嵌入版Vite编译及104项离线测试通过，原生编译、方向切换和双端实机待复核。

安卓启动图标已用内置imagegen生成独立透明母版，导出旧系统5种密度、自适应前景背景与Android13单色资源，生成提示词与素材记录在android-icon-imagegen.json。日历计时改用单调时钟，切后台和恢复时重置基准；单机弹窗暂停背景场景绘制。105项离线测试通过，包含慢帧跨日及暂停恢复回归。d58425a的浏览器结果为67通过、4失败，其余因失败上限未完整执行。该轮失败涉及桃源乡房间号时序、WebKit日历、节奏游戏与联机移动，保持开放。

固定签名已配置：创建长期RSA证书及PKCS12密钥，私钥与口令保存在本机仓库外备份，并加密写入仓库Actions Secrets。release构建递增versionCode，交付校验固定SHA256证书指纹；旧调试版首次迁移需先导出后重装。当前阶段待Actions验证release签名和真机覆盖升级。

主屋饮茶被用户补充为方块问题的具体入口，新增tea.spec浏览器回归，检查冷启动走近茶桌、倒茶、坐姿纹理透明度及色彩、起身与截图。新增手动触发的Interaction visual checks，独立运行饮茶和显示缩放，避免被全量测试失败上限跳过。已查看d584提交的WebKit主屋座椅、牵手、回忆室和足浴四张截图，该范围内贴图正常；安卓饮茶尚未证实修复。联机移动测试改为前台按住方向键直到实际位移，保留远端同步及独立移动断言。

用户确认饮茶异常出现在茶壶/茶杯。检查发现PlaceEffects的tea分支在原茶具附近叠加两组实心浅色矩形；已移除矩形，仅绘制热气和细水流，原茶具贴图保留。增加无实心遮盖的绘制回归，106项离线测试通过。专用三浏览器饮茶截图仍待新提交执行，安卓画面尚未实测。

读取3662e9f失败快照，节奏游戏显示12/15秒且已命中12音符，检查发现回合计时随渲染帧并被0.12秒截断。节奏谱面改用实际经过时间，命中使用事件时刻，长按累计只取实际覆盖区间，暂停/切后台重置基准，其他物理游戏保留步长上限。TypeScript与107项离线检查通过，浏览器节奏回归待运行。
