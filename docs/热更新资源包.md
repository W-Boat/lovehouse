# 热更新资源包

当前完成了签名资源包的构建基础。安卓端的下载、切换、失败回退与设置入口尚未接入。

Android Actions 在正式 APK 构建后额外输出 lovehouse-content-update 构件，包含 update.json 和 lovehouse-content.zip。

update.json 包含原始签名载荷的 Base64 和 SHA256withRSA 签名。载荷包含格式版本、递增资源版本、requiredNativeApi、入口、压缩包大小与 SHA256、签名证书指纹，以及每个文件的大小和 SHA256。

签名密钥与 APK 固定签名使用同一个 PKCS12 密钥，来自 Actions Secrets。构件包含公开签名信息和网页资源。

构建脚本为 tools/package_hot_update.py，原始生产目录使用 dist。输出目录必须在资源目录之外，构建拒绝符号链接、隐藏文件和不适合跨平台的文件路径。

已通过4项离线回归，验证签名、篡改检测、逐文件一致性和不匹配证书等边界。另用临时测试密钥对本地生产目录完成295文件的打包试验。该试验包仅存于构建临时目录。

下一步将由安卓原生下载器验证签名和资源完整性，解压至独立版本目录，验证入口后切换，启动失败回退。内置完整离线包继续作为恢复来源。

更新地址需要提供可访问的 HTTPS update.json，清单和同目录的 ZIP 必须共同上传到用户选择的位置。当前没有默认更新站点，也没有执行站点部署。
