# 角色图集制作用稿

本批使用内置 ImageGen，人物、服装和像素轮廓以此前游戏内的 walk、actions、heads、holding、couple 等图集为参照。输出原图编号见 actor-imagegen-sources.json，游戏使用 public/assets/actor-art-v3 下的 WebP。按透明间隙对齐再切图，禁止把单人头部叠到双人姿势上。

- 默认版：男女主各一套四向步态和站、坐、反应、舞蹈；另画坐姿过渡、泡脚、四向牵手、拥抱、摸头、送花和分享。
- 发型版：女主短波波、单侧小马尾、双侧发束，男主规整侧分、短低马尾、外翘发束，各画四向站行坐、反应舞蹈、坐下过渡。
- 露眼侧分：灰粉色侧分波波头，浅色发夹，刘海扫到两边，正面可见双眼，侧面可见近侧眼；完整保留蓝白衣服、棕鞋与猫包。分别生成走路、站姿、坐姿、动作、牵手和双人互动。
- 组合版：女主五种发型乘男主四种发型，女主在左、男主在右，保持对应发型。每格两个完整结对角色。正背牵手走路、拥抱、摸头、花朵交接、分享食物。左右牵手另画分向帧，少数组合的左右方向各使用一张明确的侧身姿势。
- 图集规格：等距行列，透明底，留出足够透明边缘，无标签、地板和游离头部。保留头、手与脚的完整轮廓。

重新打包：从项目根目录运行 `python tools/pack_actor_art.py <原图目录> tools/actor-imagegen-sources.json`。需要 Pillow 和 NumPy。
