# 桃源乡表单协作

新增 guest-only taoyuan-field 消息，固定字段 route/index/tag/inputType/value/checked。服务端验证 /game 路由、0–1000 整数索引、控件标签与类型组合、值最大一万字符、布尔 checked，每秒最多20条。拒绝密码、文件、隐藏控件，不接受任意选择器与可执行代码。

iframe桥接仅捕获允许的 input/change，主玩家端同路由、同索引、同标签、同类型才接收；disabled/readonly、maxlength及下拉选项额外检查。主端通过原生 value/checked + input/change 事件更新 Vue，仍由主端权威存档。

副玩家编辑草稿按路由和索引保存，接收周期状态后恢复输入与Vue模型，点击提交按钮后清除草稿。页面切换不会把旧路由输入错误写入新页面。联机主副玩家断线时均显示只读遮罩并禁止键盘和按钮，返回主空间按钮在父页面仍可使用。独立单机入口不受联机断线限制。

协议纯状态机测试通过，桥接TS语法检查通过；完整上游构建与双端实际表单测试仍须CI验证，不以协议测试冒充UI验收。当前不支持多选select、富文本contenteditable及文件传输。
