# 美术与构图

像素生日探索游戏，世界坐标 640×426.667，最近邻纹理采样。奶油色软垫、深木框、玫瑰色织物与蓝紫夜色保持统一。

场景主体可以在中央。双人座、茶几、足浴池、药水台、花车或舞台构成画面重心；配套道具围绕主体成组摆放，动线绕过家具。避免把所有家具推到后墙、让前半幅成为空白地板。

新场景和角色动作由内置 imagegen 制作。原图在 tools/art-source，游戏使用 public/assets 中压缩后的 WebP。引擎负责透明边界裁剪、图集播放、模块着色与前景分层；不以压扁站立图片代替坐姿。

两人的默认造型为原创角色。女孩为灰棕短发、蓝白竖条衬衫、黑短裤、猫咪斜挎包；男孩为棕色乱发、米色衬衫、橄榄色马甲与棕色长裤。动作图必须参照同一身份，不能因牵手或拥抱而更换发型和衣服。

工具、礼物、背包与地图使用同套像素图标。出口名称由屏幕 UI 绘制，保持固定字号与触摸面积，避免相机放大造成文字巨大、锯齿突出。

原始生成提示词及后续修订记录保存在 docs/imagegen-v2.json 等清单。当前内置工具实际返回静态图集；GIF 预览由图集帧合成，未声称原生 GIF 输出。
