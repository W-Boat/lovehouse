# 美术方向

蜂蜜木色、奶油墙面、红棕木框与蓝紫夜色；暖光、花束、三角生日旗，让生日有仪式感。切顶单房间主场景，海岸花园为独立附加空间。借鉴经典俯视生活模拟游戏的空间和像素质感，所有画面、角色与界面重新制作。

- 场景逻辑 640×426.667（保持 imagegen 3:2 构图完整）；最近邻采样。
- 可交互场景与 HTML 清晰中文界面分层。
- 自绘木框、羊皮纸弹窗、背包式四格工具栏；不复制商业游戏 UI 图片。
- 当前素材属于 draft / 可玩美术初版。女孩为四方向站立与两种迈步帧，男孩仍使用四方向立绘。
- 角色默认外观为原创占位，没有推断用户两人的样貌。
- 生成模型没有生成任何真实生日月相或真实 LABUBU 款式。月相卡装饰不用于天文事实。

本次实际调用 imagegen 5 次：小屋、海岸花园、角色图集、礼物图集、熄烛小屋。原始图像保留在 `/workspace/generated_images/`，副本放在 `public/assets/`。角色按 4×2，礼物按 4×3 规则格提取；运行时仅按透明边界裁切并缩放，未借用第三方商业游戏资产。提示词见 `tools/imagegen-prompts.json`。UI 图形与标记来自代码。
