# 校园、主屋猫猫与唱片房

本轮按用户要求延期验收：只做代码与资源制作、TypeScript 编译、生产构建和 Actions 安装包；未发起新的浏览器或实机验收。此前验收记录仍保留，不把本轮内容标为已验收。

## 某平一高

入口：云上终点站 → 遂平 · 嵖岈山 → 某平一高。世界地图也可查看；到访后可快速旅行，作弊模式可直接前往。

以遂平一高为题材的化名像素校园，使用 ImageGen 独立绘制。公开文字资料不足以校准校舍布局，因此不是现实校园的测绘复刻，也不使用其他学校的照片冒充。参考：

- https://www.gx211.cn/school/schoolcontent2275.shtml
- https://www.htu.edu.cn/physics/2026/0828/c1829a402514/page.htm

场景内容：教学楼上课铃、银杏布告栏、操场投篮、纸飞机、校园广播音乐切换、点心分享、银杏叶书签拾取、毕业册留言、合影、两组双人长椅。投篮、纸飞机、铃声光波和落叶在场景内表现。广播切换为已署名的离线乐曲，不伪造真实学校广播录音。

## 主屋猫猫

团团在主房间有猫窝、饭碗和绒线球，可以摸摸、喂食、逗玩、开启跟随或让它回窝。跟随选项保存在存档中，使用地面寻路，不瞬移穿家具。接近摸猫时会停下来等你；离开主屋后它留在家里。原猫猫小屋继续保留。

## 两个人的唱片房

入口在主房间，世界地图同时展示。

- 大唱片机、真实专辑封面、旋转唱片和独立唱针；已用 ImageGen 去除底图中静态唱针，避免动画与背景重影。
- LRC 歌词按音频时间投影到木地板，保留上一句／当前句／下一句；无歌词的纯音乐明确显示纯音乐提示。
- 歌单逐曲选择、上一首／下一首、播放／暂停、喜欢收藏、点歌纸条、两组双人听歌座位、歌词亮度切换、合影。
- 换曲先抬针并减速，随后落针。离开房间停止专属播放器并恢复当前区域背景音乐；不抢占角色的方向键。
- 合影包含歌词。远程封面若不允许画布读取，以曲名纪念卡替代，避免图片无法导出。

### HeoMusic 接入

使用 HeoMusic 仓库固定提交 cf9ac5a1164fd77be85614be03c29ad6c586592d 中的 APlayer／Meting 播放内核，页面布局改为游戏场景。保留许可证与来源；Meting 仅增加实例就绪／失败事件和加载中销毁保护。

来源：https://github.com/zhheo/HeoMusic 。固定文件和 SHA256 记录在 public/heomusic/UPSTREAM.json。

唱片控制面板 → 歌单 → 配置歌单／音源，可设置平台、歌单／专辑／单曲 ID、Meting API 和直链列表。设置随存档导入导出。

默认使用已有的 Moonlight、Childhood 两张 CC BY 4.0 离线纯音乐，继续保留 Scott Buckley 的署名。启用在线模式后，可填写 QQ 音乐／网易云音乐／酷狗歌单；预填 HeoMusic 官方示例歌单 ID，不擅自下载和打包商业歌曲。在线歌单、网络音频和歌词需要联网，其可用性尚未验收。

可直接修改 content/music-room.json 设置出厂歌单；每首直链歌曲字段为 name、artist、url、cover、lrc。lrc 是 LRC 文件地址，空字符串表示无歌词。相对音频放在 public/audio 或 public/music，封面可放 public/assets，推荐网络地址使用 HTTPS。
