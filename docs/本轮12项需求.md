# 本轮 12 项修改记录

日期：2026-11-13。此记录仅针对本轮追加需求，不能替代原 Requirements audit，也不代表先前所有计划均已验收。

| 项目 | 实现与验收范围 |
|---|---|
| 1 交互遮罩和动画 | 移除菜单背景遮罩和模糊，普通场景物件直接响应；拆礼物和全部饮茶点接入 ImageGen 16 帧动画，并输出 GIF 预览。其他场景仍使用已有素材和程序动画，尚未逐项重绘为独立 GIF。文字输入、设置和礼物说明保留无背景遮罩面板。 |
| 2 DPI | 默认 80，范围 50–160、步长 5；滑条、预设、15 秒确认回退。旧存档保留合法值。地图按礼物计数实际高度避让；小游戏扩大区域，触控目标独立补偿缩放。 |
| 3 摇杆 | 固定物理直径 108px，内缩 42px，底部 34px；旋转和 DPI 坐标补偿；捕获指针期间不因离开边界停摇杆。 |
| 4 作弊 | 设置→进度开启，支持所有区域快速旅行，一键解锁互动、小游戏记录和全部礼物；不开启时保持原流程。 |
| 5 许愿 | 工具栏／设置→进度进入；星轨、流星、放射光、揭晓阶段；单抽自动走到礼物旁拆开，全抽直接珍藏全部，支持跳过动画、减少动态及去重。 |
| 6 默认日期 | 新存档 2026-11-23，日期天气系统默认开启；保留旧存档明确设置。 |
| 7 贴图 | 男女主行走图集导出上限从 512 提高到 1024，换装关闭平滑；行走固定像素比例，短暂停步保留 100ms 连贯动画。尚需实机确认偶发闪现是否完全消失。 |
| 8 UID | 默认“自动珍藏”替换为 UID:5201314，存档失败仍显示明确错误。 |
| 9 成就 | 半透明全屏页面、8 项真实进度判定、非阻塞达成通知；无虚构奖励、未达成不亮起。 |
| 10 再入场 | 未进入前隐藏关闭按钮，忽略 Escape 和背景关闭；明确点击继续或装扮完成才能进入。 |
| 11 恢复位置 | 每 3 秒、失焦隐藏、离开页面保存区域与双人合法地面位置；重新进入加载该区域并恢复，损坏坐标被丢弃。联机位置以房间服务器为准。 |
| 12 底部按钮 | 所有礼物小游戏底部固定暂停／选项／退出三个按钮，选项内有提示、重试、跳过；暂停时仍可操作选项。 |
