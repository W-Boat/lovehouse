# 给你的生日小屋

独立的原创像素生日网页小游戏。Phaser 3 + TypeScript + Vite，不接入校园项目。

## 运行

```sh
npm install
npm run dev
npm test
npm run build
```

`npm run dev` 后打开 Vite 输出的地址。静态发布目录为 `dist/`，支持以 HTTPS 链接访问。已创建的 Sites 版本默认为仅拥有者访问；要让另一位访客打开，需要在 Sites 分享设置中授予访问，不要把私密文本当作加密内容。前端文件对获准访问的人可见。

## 体验

加载后自动进入 → 自由点击物件或移动 → 12 类礼物自由拆封 → 随时在蛋糕前许愿 → 读信 / 导出合影 / 继续逛。走近小屋下方的门，推门或走出门槛前往海岸；在户外走近屋门可回到小屋。场景切换没有工具栏直达按钮。树下长椅、海边秋千、海景与沙发支持两人停留；点击“起身”继续走动。

- 桌面：WASD / 方向键，E 互动；点击物件自动绕开家具走近。
- 手机：横屏优先，触摸摇杆、互动按钮、轻点物件；竖屏自动使用旋转后的横向游戏布局，并校正点击与摇杆坐标。
- 礼物手记：已拆礼物可重看，未拆礼物会带你走到对应位置。
- 音乐：首次主动点击后才允许播放，默认静音；顶部按钮始终可用。默认音轨由 Web Audio 合成原创简短旋律，不使用商业游戏或明星歌曲。
- 设置：减少动态效果、二次确认后重新体验。
- 合影：导出无操作控件的 PNG，支持下载、支持时系统分享，也可长按预览图保存。未承诺所有手机直接写入相册。

## 内容配置

集中编辑 `content/birthday-config.ts`：昵称、生日显示文案、出生日期、月相图片、信件、便签、礼物短赠言与款式、神秘礼物图片与揭晓文字、音乐文件。图片放入 `public/assets/`，路径用 `/assets/文件名`。真实外观更换对应角色图集；`characterAppearance` 是美术备注，不会自动生成新角色。

名字默认为“你 / 我”。生日、真实月相、LABUBU 款式和神秘盒子内容均未猜测。信件和个性化赠言包含明确待填写 / 示例标记。月亮图标为装饰图案，只有日期和真实月相图都配置后才显示已配置卡片。

`mysteryBoxUnlockMode` 可选 `anytime` 或 `afterCake`。LABUBU 未配置具体图片时只展示密封盒与现实拆礼提示。

## 存档与隐私

只在当前浏览器 localStorage 保存版本化的拆礼物、许愿、帽子、手环、音乐和动态效果偏好；换设备或清除浏览器数据会丢失。读取损坏或旧格式时安全恢复。无账号、无后端、无分析埋点，不请求麦克风、相机、定位权限。不要把真实姓名、私信或照片提交到公开仓库。

## 素材与验证

见 `docs/art-direction.md`、`docs/asset-manifest.json`、`docs/test-report.md`。背景、角色方向图集、礼物图集与熄烛背景均由本次实际调用 imagegen 生成。素材为原创生成，不复用《星露谷物语》的资产或 UI。

当前图集为可玩美术初版：女孩有四方向站立与两帧迈步，男孩仍使用四方向立绘；秋千采用两人轻摆的简化动画。没有提供商品截图，未验证真实商品外形。未做真机性能、手机相册或屏幕阅读器实测。

## 本次交互修复

场景启动不再提前访问 Phaser 尚未注入的事件插件。加载显示进度；失败 / 超时可重试。游戏画布占满网页视口，HUD 叠加其上。进入后不自动弹对话：远处点男孩只会走近，到身边再点才聊天。

首次操作或点击右上角全屏键，会尝试全屏与锁定横屏；浏览器拒绝时继续使用 CSS 横屏布局，不阻断游戏。应用内浏览器的顶部栏属于宿主界面，网页不能保证隐藏。

## 四场景氛围版

现在资源加载完成后会自动渐亮进入，无需点击开始。第一次真实操作时再尝试全屏、方向锁定与音频恢复；浏览器拒绝时不会弹出阻断提示，仍可使用横向布局游玩。

小屋 → 海岸 → 萤火森林 / 星光栈桥，全部通过场景中的门或小径往返，没有菜单传送。

- 远处点物件只会走近，到达后出现物件旁的动作提示，再点或按 E 确认。
- 提示显示具体动作，例如“拆开、坐下、看星星”；走近过程可取消，无目标时互动键变暗。
- 人物和环境对话使用底部纸质小面板，显式关闭或 Escape / E 退出；暂停走动但保持环境可见。
- 新增热茶、添柴、花香、看月亮、风铃、海螺、野餐、萤火、点灯、许愿泉、树下空位、望远镜、瓶中信、潮汐与流星。
- 和门口男孩对话，选择“陪我走一走”会开启室内外自动跟随；对话时停下，坐下时并肩。萤火、灯光、热气、水纹、流星和原创合成风声提供轻微氛围变化。
- `content/places.ts` 集中修改新地点文案；`src/world.ts` 配置场景、可达点、出口和道具。新的 `moments` 存档字段向后兼容旧版本，不清除已拆礼物。

素材仍为原创 imagegen 生成，新增森林、栈桥、八件道具的图集。女孩已按参考图重绘并提供四方向行走帧；男孩保持原形象，秋千座椅底图固定。浏览器视觉与真机表现仍需实测，详见测试报告。

## 碰撞、跟随和生日特效

- 可控制的是蓝白条纹衬衫、棕灰披肩发和斜挎猫咪包的女孩，形象由用户参考图改编。门口男孩没有换成该形象。
- 对话里点击“陪我走一走”直接开启自动跟随，保存到本地；男孩按实际脚步队列跟随，转弯不抄近路穿家具，停止后保持约 30 个逻辑像素的距离。跟随不再只限户外，坐下/对话暂停，起身和切场景后恢复。
- 森林和海岸使用开放地面多边形；房间采用家具脚部占地。寻路使用 4 像素格与每段碰撞校验，摇杆和跟随共享同一套判定。
- 点击蛋糕后是全屏像素烛光特写，点击吹灭后有烟雾，随后为全屏烟花与两人背影；约 8.5 秒后回到生日菜单，也可随时跳过。许愿前关闭不会记作完成。减少动态效果时改为静态烟花并缩短展示。
- 演出期间可通过左上角按钮静音。动画由 `src/celebration.ts` 的低分辨率 Canvas 实时绘制，不使用商业游戏素材或音频。

## 部署到子目录（例如 /birthday/）

运行 `npm run build` 后，把 `dist/` **里面**的 `index.html` 与 `assets/` 放进服务器的 `birthday/` 目录，再访问 `/birthday/`。不要在里面再多套一层 `dist/`。

项目默认 `base: './'`；生产素材地址以实际 JS 文件目录为准，同一个构建包可用于域名根目录、`/birthday/` 或更深的子目录，无须修改源码里的图片 URL。CSS 和入口脚本也使用相对地址。

若贴图失败，入口会停在可重试的加载界面，不会用 Phaser 绿色缺图占位继续启动。重新上传完整构建产物无需清除浏览器存档。
